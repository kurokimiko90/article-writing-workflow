# Swiss Red（C 方案）

**用途：** 文章与社交媒体（note、手机 feed）上的说明型配图。比 warm-paper 更有穿透力：大标题、粗黑线、墨色线条、只有一个朱红焦点。

**来历：** 2026-10-30，用户认为 warm-paper「好看柔和，但对社交媒体传播不够有穿透力」。比较了 A 深色海报、B 新粗野主义、C 瑞士大字之后选定 C。独立审图（20 张，P0 6 / P1 47）的系统级规则写进本文件和 `swiss-red-skin.py`。

## 出图流程

1. 结构照常按 diagram-design 加 warm-paper 画（保持 warm-paper 色义：莱姆＝焦点、薄绿框＝焦点框、青绿＝事实和连线），跑 `warm-paper-build.py visuals/diagrams/`，通过间距检查与 lint。
2. 换皮：`python3 <skill>/scripts/warm-paper/swiss-red-skin.py visuals/diagrams visuals/diagrams-C --article article.md`，原图不动，输出到 `diagrams-C/`。
3. 文章引用 `visuals/diagrams-C/…png`。上传 note 时用改了引用路径的副本（例如 `article.C.md`），草稿绑定按文件夹共用。
4. 审图看 `diagrams-C/` 的 PNG，并按本文件的规则判断，不按 warm-paper 的配色判错。

## Tokens

| 角色 | 值 |
|---|---|
| 背景 | `#F4F3EE` |
| 墨色（正文、线、箭头、框、人物、图标） | `#0A0A0A` |
| 焦点色（唯一强调） | `#FF3B1F` |
| 焦点浅底 | `#FFE7E1`（每图最多 1 处） |
| 白卡片 | `#FFFFFF` + 2px `#0A0A0A` 描边，无投影 |
| 灰背景条 | `#E4E1D8`（只放墨色大字，不放小字） |
| 分割线、装饰描边 | `#CFCCC3`（1–2px） |
| 次级文字 | `#4A4A4A`；三级文字最浅 `#6B6B6B`，禁用 `#999` 做文字 |
| 标题 | 56px、weight 800、`font-synthesis:none`、字距 +0.02em；关键词用朱红文字（不用底色高亮）；下方 8px 墨线 |
| 线宽 | 连线、箭头 3px 墨色；虚线 2.5px、dash 8/6；卡片框 2px |

## 规则

- **一图一焦点：** 朱红只给一个焦点（一个色块或一组文字），而且要和标题的红字是同一件事。序号、徽章、AI 芯片、眼睛、加号、箭头标签一律用墨色。换皮脚本的做法：warm-paper 的青绿（accent）全部变墨，只有莱姆元素和焦点框内的强调文字变红。所以画 warm-paper 原图时，焦点必须用莱姆或薄绿框标明，标题 `<mark>` 必须指向同一件事。
- **黑底上的字一律白色（2026-10-30 用户指正）：** 原来墨绿底的色块换皮后变黑，里面的字必须是白色（焦点红字除外）。脚本按 `rect` 和 `circle` 的范围判断；半透明的浅底不算黑底。用 `path` 画的深色块脚本判断不了，画原图时深色块请用 `rect`。
- **人物图标要一眼看出是人（2026-10-30 用户指正）：** 头和肩全黑会糊成一团。脚本把头画在肩的上层、稍微上移，再加一圈底色描边隔出脖子。新画人物图标时也要让头和肩之间有可见的空隙。
- **不用灰箭头，不用拟物：** 投影、纹理、胶带、折角、卡片旋转一律删除，换皮脚本会自动去掉 `filter`、`rotate` 和半透明小矩形。
- **画新图时就按手机来设计（审图 S1，换皮脚本做不到）：** 画布高宽比 ≤1.6:1，节点标签 ≥28px（weight 700），说明 ≥22px，一张图约 60 字以内。图下方的灰色脚注不放在图里，写进文章图注。信息太多的图拆成两张，或只保留主干。现有图仍是 16–22px，在 feed 里只有标题读得清。
- **图里的数字和名词要在文章里找得到（审图 S7）：** 图不能比文章多出事实或结论。

## 封面（note 見出し画像 1280×670）

沿用缩略图式的版式：一个关键词极大，加作者头像。配色改用本系统。
- 米白地 `#F4F3EE`，所有图形用墨色，朱红只给那一个关键词（约 220px）。
- 顶部一条 10px 墨线，和配图标题线呼应。
- 示意图形用白卡片加 3–4px 墨框，不旋转，不加投影。
- 头像后面放一个 `#E4E1D8` 灰圆，头像描边是白边外面再加一圈墨色细线。
- 范例：`exports/articles/ja/article-writing-workflow-story/visuals/cover/cover.html`。

## 已知限制

- 换皮只改颜色、线宽和标题，不改版式。所以留白失衡、过密、字号不够这类问题（审图 S1、S8）要回到 warm-paper 原图重新排版。
- 固定尺寸页面（没有 `wp-crop`，如九阶段图、实例图）按 body 的宽高截图。如果改了页面高度，记得同步改 body 的 `height`。
