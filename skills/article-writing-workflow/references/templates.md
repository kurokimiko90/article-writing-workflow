“当前状态”每轮更新、保持简短，历史留在原表。修改前列出受影响正文、图、图说、HTML、译版或 PPT，写入待同步项；逐项验证后才能清除。原因可用事实补充／内容探索／文字理解／图文不符／同步遗漏／排版问题／规则冲突，不把内容探索算作执行错误。

新审稿与审图报告放文章根目录 review/，按主 Skill“工作状态与审核记录”加入日期、语言、依据版本、阶段（审图）及连续轮次；派发前检查文件是否存在，存在即递增，禁止覆盖。报告记录正文与图档校验值、范围、上一轮报告和问题验证结果；旧 visuals/review/ 报告原位保留。只在实际审核时创建目录及报告，仅文章模式也适用。

审核正文时检查语言节奏：长短句与段落是否自然变化，是否连续同构、碎句过多、长句拖沓或转场突兀。将实际问题的位置、调整与通读结果填入“审核与修订”，不另设评分表。

第 07 阶段在初稿语言修订后、文章配图前进行独立文字审稿。语言修订在上述表中记录主要修改位置、原问题、具体改法及对照结果；核对事实、核心观点、重要信息、数字、否定、条件、不确定性、适用范围与立场没有改变。不只填写“更自然”或“去 AI 味”，不另建评分或重复日志。嵌图后记录图文衔接检查，以及正文改动处和新图说的独立复审结果。

## knowledge-base.html 与 knowledge-base.md

基础知识稿以HTML交给人类审阅；Markdown作为同内容文本来源。两份使用相同版本和确认状态，修改后同步。

HTML应包含完整知识稿、目的与来源、章节导航、条件与限制、待确认事项及确认记录。采用可离线打开的单文件，支持手机阅读和打印；正文与编辑备注清楚区分。候选阶段显示“待确认”，只有人类明确回复批准才更新状态。交付时优先打开并链接 knowledge-base.html。

选择知识图解时，在 G2 后完成机械检查、逐图目视、以已确认知识稿为依据的独立审图及修正验证，再按对应章节嵌回 knowledge-base.md／knowledge-base.html，附准确图说与替代文字。Markdown 引用实际 PNG 相对路径；HTML 内嵌图片数据，原 PNG 与 HTML 图源仍保存到 visuals/diagrams/。打开 HTML 检查手机、离线与打印显示；不只交一组独立图档。只嵌图与排版时保留已确认 B 版本，审核状态与知识确认状态分开记录，不新增 G2；图文需要改变实质知识时沿用重新 G2 的规则。

各大分类下使用条列式：一条一件事，以简短主题标签说明事实、动作或结果，必要时再分一层。保留完整依据和限定条件，避免长段落或流水账；正文知识与待确认备注分开。下列模板按实际主题调整，不强制每篇使用同样分类。

```markdown
# 已确认知识基准
- 版本：B1.0
- 状态：候选／人类已确认
- 确认人及日期：…

## 目的与核心观点
- **目的：** …
- **核心观点：** …

## 启发与价值
- **核心启发：** 一句话。【依据 C／E／K；作者原话／AI 推论】
- **新理解：** 常见认知是…；本案发现…。
- **张力与代价：** …
- **可迁移做法：** 2–4 条，各附依据。
- **适用前提：** …
- **建议故事主线：** 切入情境 → 转折 → 落点。

## 分类标题
- **主题：** 一个明确的事实、职责、行动、判断或结果。
- **另一个主题：** 必要证据或案例，以及适用条件和限制。

## 来源与待确认事项
- **来源：** …
- **可公开范围：** …
- **待确认：** …
```

确认前保持候选。来源至少有可定位的名称、网址或文件位置，以及必要日期和情境。

## article.md

正文以真实文章呈现。文章版本、知识基准版本和审核状态记在 working.md，避免将内部标记混入定稿。配图位置和图说明确，链接实际图档。可选标题方案不计入正文篇幅。

## 最终交付核对

- 文章符合目的及作者决策，已有 G3 批准。
- 基础知识稿HTML完整可读，与Markdown来源、版本及确认记录一致；选择知识图解时已将审过的图嵌回对应章节，HTML 单文件离线可看图，原 PNG 与可编辑来源保留。
- 句子与段落的长短、疏密和停顿自然，通读顺畅；节奏修改未改变事实、逻辑与限定条件。
- 已完成语言修订与独立文字审稿；修订前后核对事实、核心观点、重要信息及作者立场，无补造细节或故意口语化。文章配图前的文字阻挡与必修项经复审验证解决；嵌图后已检查图文衔接，正文改动处及新图说已完成必要复审。
- 所选图片／PPT 的真实文件、可编辑来源、图说／必要备注齐全。
- 知识图解依据已确认 B 版本逐章制作（默认 diagram-design＋warm-paper，用户明确风格优先），对应构建、间距及机械检查无未处理错误，警告逐项判断；短标题 ≤16 字，高亮可选、使用时最多突出一个主要讯息，图内文字 ≥16px；徽章不压字、图例与实际颜色一致；README 有短标题与忠实度说明，PNG 已逐张查看，并已按知识稿独立审图、修正验证。
- 配图依据最新故事文章，说明型图用 diagram-design、叙事图用 article-figures；每图有所用 Skill、章节和原文对应、文字校对及实际图片检查记录。
- 事实、数字、图面连接和结论一致，阻挡与必修问题已解决。
- 引用对照与定稿版本一致；修改连动产生的 Q 项均已验证关闭。
- 当前状态与实际版本、确认记录、未解决项及待同步项一致；新报告命名不覆盖，Q 项能定位报告与原问题。原样复用图有有效报告及校验值并核对当前语境，改图已按范围复审，文章变体未覆盖知识稿原图。
- 摘要、案例、来源、条件、状态与版本记录完整。
- 缺失工具、文件或待确认事项明确说明，不以规划代替成品。
