# 任务选项与默认值

每栏可选或自由输入；空白使用默认。只有原始材料本身不能预设。默认设置不代表批准事实或最终成果。

| 类别 | 字段 | 选项（均可自定义） | 未填时采用 |
|---|---|---|---|
| 写作需求 | 目标读者 | 一般读者／初学者／有经验的实务工作者／管理者与决策者／专业研究者 | 对主题有兴趣、缺少专业背景的一般读者 |
| 写作需求 | 文章目的 | 解释知识／提供操作方法／分享经验／表达观点／协助决策 | 解释知识，让读者理解并知道如何应用 |
| 写作需求 | 发布渠道 | 部落格或网站／社群长文／电子报／内部知识库／尚未决定 | 部落格或网站；此项不授权发布 |
| 写作需求 | 篇幅 | 短篇 800–1,200 字／中篇 1,500–2,500 字／长篇 3,000–5,000 字／依内容决定 | 中篇 1,500–2,500 字；材料不足不硬凑 |
| 核心方向 | 核心一句话 | 用户填写／AI 提取 | AI 从材料提取候选观点，在 G1 确认 |
| 核心方向 | 读后结果 | 理解概念／学会方法／重新思考／比较并决策／采取行动 | 理解核心概念，掌握一个可执行的下一步 |
| 原始材料 | 材料类型，多选 | 草稿／零散笔记／访谈或逐字稿／研究资料／个人经验／案例 | AI 依实际材料辨识 |
| 原始材料 | 处理方式 | 尽量保留原文／允许重组与改写／只提取核心知识 | 允许重组与改写，保留原意及重要细节 |
| 证据来源 | 来源提供方式 | 已附来源／部分附来源／未附来源 | 未附来源，标记需查证主张；收到来源则如实记录 |
| 证据来源 | 补充查证 | 仅提供材料／搜索公开来源／先列缺口再决定 | 对影响结论的事实搜索公开来源，优先原始或官方来源 |
| 表达偏好 | 语言 | 繁体中文／简体中文／英文／跟随材料 | 跟随材料主要语言，无法判断时繁体中文 |
| 表达偏好 | 定稿后日文翻译 | 不需要／定稿后翻译成日文 | 不需要；用户在 G3 后要求时才翻译，译后必用 yomiyasu 润色 |
| 表达偏好 | 语气 | 清楚务实／专业严谨／亲切易懂／故事叙述／鲜明评论 | 清楚务实、易懂，避免空泛形容词 |
| 表达偏好 | 人称 | 第一人称／第三人称／中性说明／依材料决定 | 中性说明；个人经验保留第一人称 |
| 表达偏好 | 参考与个人说法 | 提供参考／指定保留说法／不指定 | 不模仿特定作者；保留材料中清楚且有辨识度的表达 |
| 视觉需求 | 交付形式 | 文章＋配图／文章＋PPT／文章＋配图＋PPT／仅文章 | 文章＋配图 |
| 视觉需求 | 配图数量 | 每约 10 显示行一张／1 张／2–3 张／4–6 张／AI 依内容决定 | 每约 10 个显示行一张（中文约 40 字／行、日文约 44 字／行），任何连续 10 行以上无图的段落都要补图；每张有明确解释作用 |
| 视觉需求 | 配图形式 | 流程图／概念图／比较图／数据图表／情境插画（规划中，未实现）／AI 决定 | 按内容选择，优先流程、概念或比较图 |
| 视觉需求 | 知识图解 | 每章一张／只画指定章节／不需要 | 交付形式含配图时，G2 后每章一张（diagram-design＋warm-paper，跟随知识稿语言） |
| 视觉需求 | 视觉风格 | 跟随指定配图Skill／简洁信息图／正式商务／品牌指定／自定义 | 统一 warm-paper 色系：说明型图用 diagram-design 的 warm-paper profile；叙事图（封面等）用 article-figures 当前默认风格（目前 warm-paper）。不固定复制其样式参数 |
| 视觉需求 | 配图格式 | PNG／SVG／两者 | PNG；流程与概念图另留可编辑来源 |
| 视觉需求 | PPT 场合 | 现场演讲／自行阅读／内部培训／提案简报 | 自行阅读，附必要说明与讲者备注 |
| 视觉需求 | PPT 页数 | 5–8 页／10–12 页／15–20 页／AI 决定 | 10–12 页，按内容调整 |
| 视觉需求 | PPT 格式 | 可编辑 PPTX／PDF／两者 | 可编辑 PPTX＋PDF，16:9 |
| 使用限制 | 不可公开资讯 | 无额外限制／指定姓名组织／指定数据文件 | 不公开联系方式、账号、凭证和标示的机密；私人案例去识别化 |
| 使用限制 | 不宜用案例 | 无额外指定／指定案例／只用匿名案例 | 只用材料支持且适合公开的案例；私人案例匿名 |
| 使用限制 | 必须保留 | 无指定／指定观点／指定段落／指定案例 | 核心观点、必要证据、适用条件及重要限制 |

## 应用规则

- 仅文章：忽略视觉设置。
- 文章＋配图：启用图片数量、形式、风格、格式；忽略 PPT 设置。
- 文章＋PPT：启用视觉风格及 PPT 设置；忽略配图数量、形式和格式。
- 两者都选：分别交付图片和 PPT，共享知识、数字及视觉风格。
- 自定义明确时照做；含糊时只澄清影响执行的部分，不重新询问整表。
- 原始材料中的私人资讯不等于公开许可；原文保留，成品按限制处理。
- 已有来源、明确用途或读者时按材料更新，不将事实状况强行标成默认。
- 记录各值的来源：用户指定／材料明确说明／默认。变更时只更新受影响内容。
